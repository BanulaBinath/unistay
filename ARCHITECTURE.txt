DATA FLOW EXAMPLES:

1. SLIIT STUDENT REGISTRATION:
   User → Form → API → Validation → Controller → User Model → MongoDB
                                  → OTP Generator → Email Service → Gmail
   User → OTP Form → API → Controller → Verify → Activate Account

2. EXTERNAL STUDENT REGISTRATION:
   User → Form → API → Validation → Controller → User Model → MongoDB
                                  → Payment Service → Payment Page
   User → Payment → API → Controller → Subscription Model → Activate

3. VENDOR REGISTRATION:
   User → Form → API → Validation → Controller → User Model → MongoDB
                                  → Payment Service → Payment Page
   User → Payment → API → Controller → Subscription Model → Activate
