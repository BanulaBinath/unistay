## 🎨 Design System Applied

### Colors (Matching Admin Dashboard):
- **Primary Blue:** `#5b6cf2` (buttons, active states, links)
- **Success Green:** `#14b8a6` (success indicators, accept buttons)
- **Warning Orange:** `#f59e0b` (pending states, warnings)
- **Error Red:** `#dc2626` (errors, reject buttons, delete)
- **Purple:** `#a855f7` (accent color for specific states)
- **Text Primary:** `#1a1a1a` (headings, important text)
- **Text Secondary:** `#6b7280` (body text, labels)
- **Text Tertiary:** `#9ca3af` (subtle text, placeholders)
- **Background:** `#fafbfc` (page background)
- **Card Background:** `white`
- **Borders:** `#e5e7eb` (default borders)
- **Hover Borders:** `#d1d5db`

### Typography:
- **Font Family:** Poppins (300, 400, 500, 600, 700, 800)
- **Page Title:** 1.5rem (24px), weight 700, letter-spacing -0.5px
- **Section Title:** 1.25rem (20px), weight 700, letter-spacing -0.3px
- **Card Title:** 1rem (16px), weight 700, letter-spacing -0.3px
- **Body Text:** 0.85-0.9rem (13.6-14.4px), weight 400-500
- **Small Text:** 0.7-0.8rem (11.2-12.8px), weight 500-600

### Component Styling:
- **Border Radius:** 8-10px (cards, buttons, inputs)
- **Pill Radius:** 20px (badges, status pills)
- **Box Shadow:** `0 2px 12px rgba(0,0,0,0.06)` (default)
- **Hover Shadow:** `0 8px 24px rgba(0, 0, 0, 0.08)`
- **Card Padding:** 20-28px
- **Button Padding:** 10-12px vertical, 16-20px horizontal
- **Input Padding:** 10-12px vertical, 14px horizontal

### Spacing:
- **Section Gap:** 20-28px
- **Card Gap:** 14-16px
- **Element Gap:** 8-12px
- **Border Bottom:** 16px padding + 1px border

### Transitions:
- **Duration:** 0.2-0.3s
- **Easing:** ease, ease-in-out
- **Hover Transform:** `translateY(-1px)` to `translateY(-3px)`
